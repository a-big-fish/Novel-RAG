# Novel-RAG 写作参考 · 组装 Skill

## 这个 MCP 解决什么问题

调用方（写作 Agent）通常知道**想写什么**，但不知道怎么把意图拆成检索标签，
也不知道该取多少条、怎么拼进提示词。Novel-RAG MCP 负责：

1. 把你的写作目标 + 细纲上下文 + 约束组装成检索查询；
2. 在多本书的范本库中检索；
3. 按预算去重、截断、配额并拼成提示词（或返回结构化 fragments）。

它**不写正文**，只提供写作范本与上下文。

## 什么时候用

- 开写一个场景前，需要“这个情绪/冲突/节奏别人怎么写过”的参考。
- 有细纲，但不确定如何向 RAG 提问。
- 想直接拿到能塞进写作模型上下文的提示词，而不是自己拼。

## 推荐调用

工具：`search_writing_references`

| 参数 | 必填 | 说明 |
| --- | :---: | --- |
| `writing_goal` | 是 | 一句话到一段话：写什么内容、什么情绪、什么结构或叙事功能 |
| `outline_context` | 否 | 该场景在细纲中的位置与前后因果 |
| `constraints` | 否 | 情绪、句式、视角、节奏、要避免的东西 |
| `book_ids` | 否 | 默认使用全部 ready 书籍 |
| `output` | 否 | `prompt`（默认）/ `fragments` / `both` |
| `budget_chars` | 否 | 提示词字符预算，默认 6000 |
| `max_scenes` | 否 | 最多收录多少个参考场景，默认 8 |
| `book_quota` | 否 | 每本书最多几条，默认 0（不限制） |
| `use_rerank` | 否 | 默认 false；重排是分钟级离线操作 |

### 示例 1：情绪与节奏

```json
{
  "writing_goal": "写一段雨夜追杀的紧张场景，冷峻短句，结尾留一个反转",
  "outline_context": "主角刚发现盟友背叛，追兵封锁街道，他必须在天亮前出城",
  "constraints": {"情绪": "紧张", "句式": "短句", "视角": "第三人称限知", "避免": "大段心理描写"}
}
```

### 示例 2：对话与信息释放

```json
{
  "writing_goal": "写一段两个人互相试探的对话，信息一点点漏出来，最后一句翻盘",
  "outline_context": "女主怀疑男主知道父亲失踪的真相，但两人都不能先摊牌",
  "constraints": {"场景": "封闭空间", "节奏": "先慢后快", "避免": "旁白解释"}
}
```

### 示例 3：结构参考

```json
{
  "writing_goal": "需要一个“多年后重逢、沉默比对话更多”的收束段落",
  "outline_context": "全书倒数第二章，父子在葬礼后第一次单独相处",
  "constraints": {"情绪": "克制", "篇幅": "短", "避免": "煽情"}
}
```

## 拿到结果之后

- `prompt.text`：直接作为写作模型的上下文或 user 消息的一部分，让模型续写。
- `references`：每条含 `book_id` / `version` / `scene_id`；正文中不要出现编号。
- `dropped` / `budget`：说明哪些参考因预算被舍弃；需要更多就提高 `budget_chars` 或减小 `max_scenes`。
- 想读某条参考的完整原文：调用 `get_scene(book_id, version, scene_id)`。

## 其他可用工具

- `plan_writing_query`：只预览检索查询，不执行检索。
- `build_reference_prompt`：进阶，直接给检索 query。
- `list_books`：查看书库与版本；不知道 `book_ids` 时可省略或先调用它。
- `get_service_status`：检查数据库、Qdrant、Ollama、LLM 配置是否就绪；接入调试第一步。
- `get_usage_guide`：返回服务端使用说明。

## 延迟提醒

首次未命中的查询会调用外部 LLM 做需求解析，可能数十秒到数分钟；解析结果有持久缓存，
同一查询再次调用更快。客户端工具超时应设置得宽裕；失败先查 `get_service_status`。

## 不要做的事

- **不要自己拼标签**（“紧张、短句、雨夜”）；给完整写作意图。
- 不要要求它写正文、改剧情或续写。
- 不要要求整本书；超长 Scene 会被有界采样。
- 默认不要开重排；它耗时分钟级，不属于实时链路。

## 无结果时

把目标写得更具体：人物关系、冲突、场景功能、希望读者产生的感受。
若书库没有 ready 版本，先在服务端完成索引。
